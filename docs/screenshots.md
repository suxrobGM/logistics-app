# Screenshots

Visual tour of LogisticsX applications. Captured from the live demo tenant
(Heartland Logistics LLC) at [tms.logisticsx.app](https://tms.logisticsx.app).

## TMS Portal (Angular)

The dispatcher and manager web interface for managing loads, customers, operations, invoices, payrolls, and more.

### AI Dispatch

The agent reads unassigned loads, checks driver hours, and proposes load-truck
pairings. Every tool call and every reason stays on the record, and nothing is
executed until a dispatcher approves it.
